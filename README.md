# على شو عم تدور بدوما؟ — نسخة أندرويد أولية

هذه نسخة أولية قابلة للبناء من مشروع Android Studio، بواجهة عربية تجريبية وهوية ألوان مستوحاة من ملف هوية دوما الذي أرفقه المستخدم.

## الأقسام الموجودة
- المواصلات: خط دوما–دمشق والخطوط الداخلية (معلومات تجريبية/بانتظار إدخال بيانات موثقة).
- الصيدليات، المشافي، الأطباء، المحلات والمنتجات، الطوارئ، الإعلانات.
- نموذج أولي للشكاوى يجهّز نصاً للمشاركة، ويتيح اختيار صورة وفتح الخريطة.
- بوابة رابط BeeOrder.

## حدود النسخة
- لا توجد قاعدة بيانات أو لوحة إدارة أو حسابات مستخدمين بعد.
- الشكوى لا تُرسل تلقائياً إلى المجلس، لأن قناة الاستلام الرسمية لم تُحدد.
- لا توجد قوائم حقيقية للصيدليات/الأطباء/المشافي. يجب التحقق من البيانات قبل النشر.
- لا تحتوي الحزمة على APK جاهز؛ افتح المشروع في Android Studio وابنِ APK من Build > Build APK(s).

## البناء
1. افتح مجلد المشروع في Android Studio.
2. اسمح بمزامنة Gradle وتنزيل المتطلبات.
3. من القائمة: Build > Build APK(s).
